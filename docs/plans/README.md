# Implementation Plans

Detailed step-by-step implementation plans for each development phase. These translate phase-level plans (in [plans/](../../plans/)) into concrete tasks, file-level changes, and milestones.

## In Scope

- Concrete implementation steps with file paths and function signatures
- Task ordering, dependencies, and milestones
- Gap analysis and codebase readiness notes

## Out of Scope

- High-level phase planning and scope definition (see [plans/](../../plans/))
- Research and technology evaluation (see [docs/research/](../research/))
- Architecture decisions (see [decisions/](../../decisions/))
